# Ocode 0.21.0 — Windows x64

## Changes

- Windows installed builds now use the public `diaomin66/Ocode-releases` GitHub release channel. Update discovery no longer depends on access to the private development repository.
- The Home Ocode O/slash mark is rendered as a scalable vector with transform-only motion instead of low-frame-rate raster GIF playback. The existing light/dark themes, 100px layout and reduced-motion preference are preserved.
- The Windows build verifies NSIS installation, installed and ZIP startup, native x64 Host architecture, packaged update-provider configuration and updater metadata before publishing candidate artifacts.

## Install and update

Download `Ocode-Setup-0.21.0.exe` for the normal installed application. `Ocode-Portable-0.21.0.zip` and `Ocode-Portable-0.21.0.exe` are also provided.

**One-time manual upgrade:** Ocode `0.21.0-beta.1` pointed to the private repository. It cannot discover this public release automatically. Close that application and run the new installer manually. The Ocode application ID and data directory are unchanged; this release does not migrate databases or adopt upstream PI-Desktop profiles. Back up important data before replacing an installation.

From this release onward, installed Windows builds check the public stable channel and retain the existing download/restart update flow. ZIP and portable builds keep manual updating as their default. There is no newer stable version at initial publication, so an up-to-date result on `0.21.0` is expected.

## Verification and limitations

- See `windows-verification.json` for the tested source commit, base, package identities and real installed/ZIP boot results.
- `latest.yml` describes only the NSIS installer, with its size and SHA-512. `SHA256SUMS.txt` identifies all distributed artifacts.
- These Windows artifacts are **not code-signed**. Windows may display an unknown-publisher or SmartScreen warning. No publisher certificate or SmartScreen qualification is claimed.
- Old-to-new in-app installation and portable EXE startup are not qualified by the installation/ZIP smoke tests.
- macOS, Linux desktop and remote Linux Host binaries are not included in this Windows-only release.
